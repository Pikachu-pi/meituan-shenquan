# 安装与使用

适用于 Windows 10/11，支持使用同类报名表单的美团神券活动。日常调用会提交取消和报名，并核对结果。

## 首次安装

1. 将公开仓库克隆到固定目录，运行 [`scripts/install.cmd`](../scripts/install.cmd)。命令见 [快速开始](../README.md#快速开始)。也可以在资源管理器中双击该文件。
2. 按提示填写两个中台右上角显示的美团商家账号。密码和验证码在网页登录时填写。
3. 打开对应的桌面快捷方式，手动登录并核对账号，然后正常关闭窗口。运行时脚本会核对并切换到 **全部门店**。

| 中台 | `-Brand` | 桌面登录快捷方式 | 默认端口 |
| --- | --- | --- | --- |
| 小仓 | `xiaocang` | 小仓中台登录（Edge） | `9335` |
| 乐心宜 | `lexinyi` | 乐心宜中台登录（Chrome） | `9334` |

两个浏览器分别保存登录资料，调试端口绑定本机。登录窗口设为 1920 × 1080，缩放系数为 1。日常运行复用各自的资料，以无头模式启动或连接浏览器。

首次安装直接运行 `install.cmd`。电脑只有 Windows PowerShell 5.1 时，安装器通过 Winget 另装 PowerShell 7，再用它执行后续步骤。若缺少 Winget，按安装器提示从微软官网安装 PowerShell 7 后重试。

后续步骤检测 Node.js 22.20+、Python 3.11+、Edge、Chrome、Browser Harness 和 Playwright CLI。首次安装需要访问 GitHub、Winget 源、npm 和 PyPI。若公司网络或权限限制安装，根据窗口中的组件名称和错误联系 IT，处理后重新运行 `scripts/install.cmd`。退出码为 `0` 表示安装完成。

PowerShell 7 安装后，在仓库目录运行以下命令可单独检查环境。

```powershell
& .\scripts\setup.ps1 -CheckOnly
```

首次配置时，如果默认端口已被占用，核对占用进程后，用 `-XiaocangPort` 和 `-LexinyiPort` 指定两个空闲端口。重复安装保留现有端口、账号绑定和浏览器资料。移动项目后，检查桌面快捷方式指向的脚本路径，重新创建失效的入口。

## 核验登录

在项目目录内使用 PowerShell 7。首次安装或重新登录后，先核验两边的账号。

```powershell
& .\scripts\Invoke-Shenquan.ps1 -Brand xiaocang -Mode VerifyLogin
& .\scripts\Invoke-Shenquan.ps1 -Brand lexinyi -Mode VerifyLogin
```

## 通过 Agent 调用

将完整项目目录安装为 Agent Skill。已有 `$dbs-install-skill` 时，让 Agent 用它安装本地目录。缺少该安装技能时，先执行官方安装命令，再回到 Agent 安装本项目。[dbskill 安装说明](https://github.com/dontbesilent2025/dbskill)

```powershell
npx -y skills add dontbesilent2025/dbskill -g --all
```

> 用 `$meituan-shenquan` 跑神券。

首次调用时，Agent 读取本机配置，把缺少的中台、活动 ID 和库存一次问齐。补齐后保存并正式运行。以后再调用时，Agent 告知本次参数，随后自动下载明细、提交取消和报名、核对回执。同一中台同时运行一个任务。登录过期或出现验证码时，按提示人工登录，关闭窗口后告诉 Agent 继续。

| 要做什么 | 怎么说 |
| --- | --- |
| 沿用已保存的参数并提交 | 用 `$meituan-shenquan` 跑神券 |
| 长期修改默认值 | 把神券默认库存改成 300 张 |
| 本次临时更换 | 仅这次用 300 张库存跑神券 |

## 本机配置与命令行

默认值保存在 `%LOCALAPPDATA%\MeituanShenquan\config.json` 的 `brand`、`activityId` 和 `inventory` 字段。保存默认值可以用 Agent，也可以在仓库目录用 PowerShell 7 执行以下命令。此例设置乐心宜，小仓改用 `xiaocang`。

```powershell
$activityId = Read-Host '活动 ID'
$inventory = Read-Host '每日库存'
& .\scripts\Invoke-Shenquan.ps1 -Mode Configure -Brand lexinyi -ActivityId $activityId -Inventory $inventory
```

保存后，以下命令会按默认配置提交取消和报名。`-Brand`、`-ActivityId` 和 `-Inventory` 可临时覆盖本次参数。

```powershell
& .\scripts\Invoke-Shenquan.ps1
```

## 结果与恢复

打开 `%LOCALAPPDATA%\MeituanShenquan\runs` 中的本次运行目录，先看 `结果.md`，再按需核对原始 CSV、逐店失败原因和平台回执。退出码 `0` 表示当前阶段完成，`1` 表示停止并需要核对，`2` 表示正式流程已完成回读且有门店报名失败。

| 情况 | 处理 |
| --- | --- |
| 账号不符、登录过期或验证码 | 用对应的桌面快捷方式重新登录。关闭窗口后再核验 |
| 桌面快捷方式无法启动 | 在 PowerShell 7 中运行 `& .\scripts\Invoke-Shenquan.ps1 -Brand lexinyi -Mode Login` 查看错误，小仓用 `xiaocang` |
| 可见登录窗口仍在运行 | 正常关闭该窗口，再运行无头流程 |
| 端口或运行锁被占用 | 核对进程和原任务，保留其运行状态 |
| 活动找不到、表单不匹配或库存超范围 | 核对活动 ID 和库存，按提示更正后继续 |
| CSV 缺列、ID 重复或数量不符 | 核对本次导出与页面，解决差异后再执行 |
| 报名部分失败 | 按逐店原因处理。先确认原报名门店是否恢复生效，库存是否与本次记录一致 |

出现 `pending` 记录时，提交结果尚未核实。保留原目录和浏览器会话，用原 `-Brand`、`-RunDir` 运行 `-Phase verify-cancel` 或 `-Phase verify-register` 核对对应回执。恢复时沿用原活动和库存。旧记录缺少库存且恢复步骤需要填写时，核对原值后用 `-Inventory` 补填。

出现 `active-run` 记录时，整轮业务尚未核实收尾。即使取消回执已确认，也要在原目录中继续核对报名回执和原门店恢复情况。待报名回执、门店、库存和状态均核对通过后，程序释放记录。

## 更新与迁移

升级前先处理运行锁、未决提交和未收尾任务。在仓库目录运行 `git pull --ff-only`。若 Agent 使用独立的 Skill 副本，用新版仓库更新该副本。若依赖有变更，再运行 `scripts/install.cmd`。升级后核验两个账号。换电脑时重新克隆、安装并手动登录。
